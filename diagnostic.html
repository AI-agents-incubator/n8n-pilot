⚠️ IMPORTANT: Workspace Billing Check

Anthropic Console has workspaces, and each workspace has SEPARATE billing.
The Workbench uses your account session (cookies), NOT the API key — so it uses your default workspace credits.
But your API key might belong to a different workspace that has NO credits.

To fix this:
1. Go to console.anthropic.com/settings/keys
2. Find your API key — note which workspace it belongs to
3. Switch to that workspace, go to Plans & Billing
4. Make sure THAT workspace has credits (not just your default workspace)
5. Or: create a new API key in the workspace that has credits

4. Server-Side Test (curl command)

Copy this curl command and run it in your terminal (Mac/Linux/WSL). This tests the API WITHOUT any browser headers — pure server-side call. If this also fails, it confirms the problem is with the API key's workspace billing.
